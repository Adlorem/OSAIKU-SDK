## Typed bindings

| Attribute | Type | Targets |
| --- | --- | --- |
| `bind:text` | text | Leaves |
| `bind:value` | percent | ui-value-bar |
| `bind:series` | series | ui-chart |
| `bind:hidden` | bool | Any node |
| `bind:disabled` | bool | Any node |
| `bind:selected` | bool | Any node |

Text is literal UTF-8 (at most 256 bytes per leaf). Percent is optional,
0..10000 basis points; unavailable is distinct from zero. Series contain at
most 60 ordered timestamped percent samples, including explicit missing samples.
Bool controls hidden/disabled/selected state.

## Source registration

Hosts register named, versioned `record` or `rows` schemas. Fields have a source
and one of the binding types above. Row fields belong to the matching virtual-list
prototype or materialized rows; record fields belong outside those rows.
Source names and schema versions do not authorize queries or disclosure.
Report input must be checked against the host's registered contract before binding.

## Limits

Nodes: 128; depth: 24; text bytes: 8192; series points: 120; wire bytes: 65536.
Report sources: 16; fields: 128; actions: 64.

The catalog describes existing native primitives, not browser HTML/CSS.
See [UI format](ui-v1.md) for styles, attributes and structural restrictions.
